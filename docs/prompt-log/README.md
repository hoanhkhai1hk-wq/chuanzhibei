# Prompt 链快照（AI 协同过程留痕）

> 赛题「AI 协同与意图对齐」考察的不是"用了多少轮对话"，
> 而是**人如何把意图传给 AI、如何约束 AI、如何校验 AI 的产出**。
> 本目录按 Phase 存放核心 Prompt 链：当时的用户原话、给 AI 的约束、
> 产出的落点、以及事后复盘。

## 快照约定

- 每篇记录三段：**意图（用户原话）→ 约束与上下文 → 产出与验证**
- 用户原话保留原始语气，不润色——意图对齐的难度在原话里才看得出来
- 引用的代码以仓库路径为准，不整段粘贴（代码有 git 历史可追溯）

## 快照清单

| 编号 | Phase | 主题 | 产出落点 |
|---|---|---|---|
| 01 | 立项 | 选题调研 → 两次否决 → v2 定案 | 仓库外的调研文档 + README |
| 02 | 档案层 | 端到端串联（"串起来吧"） | `app/pipeline.py` |
| 03 | 表达层 | LLM 只写人话 + 数字回溯校验 | `app/llm/explainer.py` |

## 为什么只有三篇

赛题建议"每 Phase 一条完整 commit + 关键 Prompt 快照"。
本项目的 commit 历史本身就是过程留痕（每条 commit message 详列了改动与理由，
并带 `Co-Authored-By` 标记协作边界），Prompt 快照只挑**意图最复杂、
约束最关键**的三轮，避免把日志做成流水账。
