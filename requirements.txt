# Python 依赖

# 适用：Python 3.11+（本项目在 3.11.15 实测；3.12 / 3.13 未实测）

# 版本策略：
#   · 默认链路（启动服务 → 演示模式 → 上传报告 → 判定 → 红线 → 记餐 → 周报）
#     用到的包一律 pin 死，且都是本机实测跑通的版本，不是猜的；
#   · 可选 provider（百度 OCR / PaddleOCR）只写在文末注释里，需要时再装；
#   · 默认链路**不需要任何 Key、不需要联网**（OCR 走本地 RapidOCR）。

# ---- Web 框架 ----

# ---- 大模型（可选：不配 Key 时走本地模板模式，功能完整）----
# OpenAI 兼容协议，DeepSeek / 通义 / Kimi 共用一个 SDK
openai==3.35.1

# ---- OCR：默认本地引擎，零 Key、纯 CPU ----
# 选它的理由：评委不需要申请任何账号，clone 完装完就能跑。

# Shapely / six / tqdm / Pillow，所以不必逐个列。

# 推理运行时。我们没直接 import 它，但它决定模型跑在哪一版 ONNX 上——

onnxruntime==1.31.0

# ---- 图像处理 ----

# ---- 数据处理 ----
# numpy 会被 rapidocr 一并装上；pandas 当前未被任何代码 import（已核查全仓零引用），
