拍不清楚？先看这四条
  1. 放平：把报告摊在桌面拍，不要手持悬空——倾斜会让表格线干扰识别。
  2. 光线足：在自然光或顶灯下拍，避免台灯在纸面上留下一道亮斑。
  3. 对准一行：让指标名称、数值、参考区间三列都在画面里，不要裁掉右侧。
  4. 一次一页：多页报告请分开拍，本产品按单页处理。

识别不完整的指标会在结果里标为「待确认」，并告诉你下一步怎么办——不会静默编一个数。

三层架构：一条链路，两本字典，一个规则引擎

档案层

报告 → 指标

OCR 抽出四元组 → 指标字典归一 → 本地比对参考区间 → 判定高低。
全程不调用大模型。

日常层

吃饭 → 红线

每天点选吃了什么 → 菜品库查嘌呤/钠/糖/脂肪 → 本地累加 → 对照红线。
与档案层共用同一套规则引擎。

表达层

数字 → 人话

大模型只负责措辞。所有数字由前两层定稿后注入，
输出还要过一遍数字回溯校验。

铁律：数字绝不来自大模型。少接一次模型，产品照样能跑； 这也意味着每一句结论都能追到报告上的具体数字。

解读只是起点

下次就诊问什么

按异常指标生成问题清单，直接拿着去医院。产品不替你下结论，只替你想好要问什么。

给爸妈说的话

一键生成能直接念给父母听的大白话，可复制发家庭群。看懂报告的是子女，需要改变生活的是父母。

报告不留存

图片处理完立即删除，个人信息在送模型之前就已抹除。隐私是写进数据契约的，不是口头承诺。

本产品不构成医疗建议，不能替代医生诊断。数值来自报告本身，判定基于公开的成人参考区间。
